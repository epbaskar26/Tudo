Install on your phone

  1. Open this page on your Android phone and tap Download APK.
  2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps.
  3. Open Tudo, create your passphrase, and save your recovery codes.
  4. Allow notifications when asked. On the Alarms tab, tap Allow exact alarms if it appears.
  5. On Samsung, Xiaomi, Oppo or Vivo phones, set Tudo's battery usage to Unrestricted (Settings, Apps, Tudo, Battery) so alarms are not delayed.

Data in the Android app is stored only on that phone, separately from the web app. Android may warn that the app is from an unknown developer because it is not installed from Google Play.

Updating

Download and install the latest APK over the existing app. Your tasks and alarms are kept.
